2. Description of Service

TrailMapper is a GPS trail recording and mapping application for recreational trail builders, property owners, and outdoor professionals. The App allows users to:

  • Record GPS trail segments using the device's location services
  • Build and manage connected trail networks on properties
  • Place and manage points of interest on trail maps
  • Export trail data as KML or GPX files for use in third-party mapping tools
  • Generate excavator work quotes tied to trail segments
  • Back up and restore trail data via the Android Storage Access Framework
